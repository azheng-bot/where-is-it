## MODIFIED Requirements

### Requirement: GPU 服务内部推理请求可追踪且有界
GPU 推理 API 服务中每个内部视觉或 ASR 推理请求 MUST 携带稳定请求关联标识、契约版本、调用时限和输入媒体或帧引用。内部运行时 MUST 回传关联标识、已使用模型版本和成功、降级或失败状态；该契约不要求成为独立网络服务的公开接口。

#### Scenario: GPU 服务调用目标定位运行时
- **GIVEN** GPU 服务已经获得一个摄像头帧引用和请求关联标识
- **WHEN** 服务向内部 Grounding 运行时发起目标定位请求
- **THEN** 请求与响应都包含相同关联标识、契约版本、时限和模型版本信息
