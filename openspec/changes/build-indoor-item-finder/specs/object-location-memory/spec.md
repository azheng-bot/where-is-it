## Purpose

本能力用于把连续视觉观测转化为可查询的物品位置记忆，严格区分当前检测事实、最后出现事实和预测结果，并通过限量证据图片、时间戳和推测依据支持用户核验。

## ADDED Requirements

### Requirement: 明确的位置状态模型
系统 MUST 为每个正式物品维护 `currently_detected`、`not_currently_detected` 和 `identity_uncertain` 等可区分状态。只有满足稳定性规则且观测处于配置的新鲜度窗口内时，才可将物品声明为当前检测到。

#### Scenario: 当前稳定检测
- **GIVEN** 某具体物品在最新画面中被连续稳定匹配到同一身份
- **WHEN** 最新观测仍在新鲜度窗口内
- **THEN** 系统将状态设为 `currently_detected`
- **AND** 记录当前 `location_id`、观测时间和证据

#### Scenario: 当前画面未检测到
- **GIVEN** 某物品曾被稳定观察但最新观测已超出新鲜度窗口
- **WHEN** 系统无法继续稳定匹配该身份
- **THEN** 系统将状态设为 `not_currently_detected`
- **AND** 保留最后一次确定观测，不得将其伪装为当前位置

### Requirement: 唯一位置与自然语言关系
每次确定观测 MUST 关联一个唯一 `location_id`；系统 MUST 在可判断时同时生成相对于该位置的关系描述，例如“书桌左侧”或“床头柜上方”。无法可靠归属正式位置时 MUST 使用唯一的未分区位置状态，不得任意选择家具名称。

#### Scenario: 物品位于书桌区域
- **GIVEN** 物品边界与“书桌”的已确认空间区域稳定相交
- **WHEN** 系统固化该次观测
- **THEN** 观测关联书桌的 `location_id`
- **AND** 保存可理解的相对位置描述

#### Scenario: 无法判断具体区域
- **GIVEN** 物品可见但不属于任何已确认空间区域
- **WHEN** 系统固化该次观测
- **THEN** 系统记录唯一的“未分区区域”状态
- **AND** 不得猜测某个家具位置作为确定事实

### Requirement: 最后出现记忆
系统 MUST 为每个曾被确定观察的物品保存最后出现时间、最后 `location_id`、相对位置描述和最后证据图片，并在后续不可见时保持可查询。

#### Scenario: 物品被遮挡
- **GIVEN** 眼镜最后在床头柜被稳定检测到
- **WHEN** 眼镜随后被遮挡且当前未检测到
- **THEN** 系统保留床头柜为最后确定位置和对应时间
- **AND** 状态仍明确为“当前未检测到”

### Requirement: 有界证据图片历史
系统 MUST 为每个物品保存最近若干次有意义观测的证据图片，默认上限为二十张且可配置。证据图片 MUST 包含时间戳元数据和可定位目标的边界信息；达到上限时 MUST 循环删除最旧的非保留证据，不得保存连续监控录像。

#### Scenario: 位置变化生成证据
- **GIVEN** 某物品从床移动到书桌并形成稳定新位置
- **WHEN** 系统提交位置变化事件
- **THEN** 系统保存该事件的证据图片和目标边界
- **AND** 将其加入该物品的最近证据列表

#### Scenario: 超出单物品图片上限
- **GIVEN** 某物品已有二十张证据且上限保持默认值
- **WHEN** 系统保存第二十一张非保留证据
- **THEN** 系统删除最旧的非保留证据文件和记录
- **AND** 最近二十张证据仍可访问

### Requirement: 不可见时最多三个推测位置
仅当物品状态为 `not_currently_detected` 时，系统 MUST 先说明当前未检测到，再基于最后观测、消失位置、历史迁移或邻近区域生成零到三个按可能性排序的候选位置。每个候选 MUST 标记为推测，并包含置信等级或分数及简短依据。

#### Scenario: 给出一个或多个可能位置
- **GIVEN** 目标当前未检测到且存在最后观测和可用迁移线索
- **WHEN** 用户查询该物品
- **THEN** 回答首先明确说明“当前未检测到”
- **AND** 给出不超过三个标记为“推测”的候选位置
- **AND** 将最后确定位置与候选推测分开显示

#### Scenario: 没有足够推测依据
- **GIVEN** 目标当前未检测到且没有足够的历史或空间线索
- **WHEN** 系统生成查询结果
- **THEN** 系统仍返回最后确定位置和时间（如存在）
- **AND** 明确说明暂时无法形成可靠推测，不得由语言模型补造位置

### Requirement: 确定事实与推测可核验
查询结果 MUST 让用户查看支撑当前位置或最后位置的证据图片、观测时间、规范物品名称和规范位置名称。确定事实和推测 MUST 使用不同状态标签和视觉样式。

#### Scenario: 查看最后位置证据
- **GIVEN** 目标当前未检测到但存在最后确定观测
- **WHEN** 用户展开回答中的依据
- **THEN** 界面显示最后证据图片、目标框、时间和唯一规范位置
- **AND** 推测区域不得使用“已检测到”等确定性标签

### Requirement: 全局存储预算
系统 MUST 支持配置证据图片的全局字节预算，并在预算超限时优先清理最旧的非保留证据，同时尽可能保留每个物品的最新一张证据。

#### Scenario: 达到全局空间上限
- **GIVEN** 图片目录达到配置的全局字节预算
- **WHEN** 新证据需要写入
- **THEN** 清理程序按策略释放旧证据空间
- **AND** 每个仍在目录中的物品最新证据受到优先保留
