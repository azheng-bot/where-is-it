# Mock camera video attribution

`indoor-living-room.mp4` is a stock private-bedroom clip with everyday bedside clutter, books, drinks, glasses, pillows, a photo frame, and a table lamp. It is served locally and looped by the mock camera endpoint.

- Source: [Pexels video 6716605](https://www.pexels.com/video/a-person-inside-a-messy-bedroom-6716605/)
- Download URL: `https://videos.pexels.com/video-files/6716605/6716605-uhd_2732_1440_25fps.mp4`
- Usage: Pexels marks this clip as free to use; re-check the source licence before redistribution outside this development demo.

The video is only a visual camera-source mock. The object catalogue intentionally continues to use the labelled `bedroom-mock.png` evidence fixture, so detections remain deterministic until actual video-frame inference is implemented.
