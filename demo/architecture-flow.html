一次“钥匙在哪里”的数据旅程

核心查询不会触发重型视频推理，而是读取已经持续更新的位置记忆。

用户提出问题网页把文字发送到 /api/query，或先上传短音频到转写接口。
API 解析候选优先使用名称、别名和模糊匹配，从对象目录召回可选对象。
读取事实包查询最后出现位置、状态、时间、证据和最多三个推测位置。
受约束回答LLM 仅负责理解与表达。超时、不可用或格式错误时，模板回答接管。
网页呈现结果先显示文字与证据入口，再使用浏览器 TTS 播报。
